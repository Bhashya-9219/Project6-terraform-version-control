# Terraform Version Control Infrastructure

## Project Goal
Track Terraform infrastructure updates using Git and GitHub.

## Technologies
- Terraform
- Git
- GitHub

## Files
- main.tf: Main infrastructure configuration
- variables.tf: Input variables
- outputs.tf: Terraform outputs
- .gitignore: Files excluded from Git tracking

## Project Tasks
- Create Terraform configuration.
- Initialize and validate Terraform.
- Track changes using Git.
- Push code to GitHub.
- Raise a Pull Request

## Version Control Workflow

- Created and managed Terraform files using Git.
- Stored the project in a GitHub repository.
- Used feature branches to manage updates.
- Followed the Pull Request workflow.
